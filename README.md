# XIAO ESP32S3 Control Module

XIAO ESP32S3 Senseを使用した、飛行艇実験用のセンサ読み取り・サーボ制御・SD記録のArduinoスケッチです。

## 現在の構成

- R3008SBのSBUS受信
- D2のPWMサーボ1と、D6のMG92Bサーボ2
- M5 Unit Ultrasonic-IOのTrig/Echo距離測定（割り込み方式）
- ADS1015によるA0−A1の差動電圧測定
- AE-LSM6DSV16XのIMU測定、GP-808GのGPS受信
- Sense拡張基板のmicroSDへのCSV記録

現在は **ADS1015有効、HX711無効、STS3032無効** です。旧モジュールのコードも残していますが、STS3032は初期化部分だけを有効にしても現在のPWM制御を置き換えられません。

## 配線（ファームウェアの信号割り当て）

| 接続先 | XIAO端子 | GPIO | 信号 |
| --- | --- | --- | --- |
| 超音波センサ | D0 | 1 | TRIG |
| 超音波センサ | D1 | 2 | ECHO |
| PWMサーボ1 | D2 | 3 | PWM |
| GPS | D3 | 4 | GPSのTX → XIAOのRX |
| IMU・ADS1015共通 | D4 | 5 | SDA |
| IMU・ADS1015共通 | D5 | 6 | SCL |
| MG92Bサーボ2 | D6 | 43 | PWM（旧STS信号端子） |
| R3008SB | D7 | 44 | SBUS RX |
| HX711（無効） | D12 | 41 | DATA / DOUT |
| HX711（無効） | D11 | 42 | CLK / SCK |

- IMUとADS1015は同じ`Wire`（100 kHz）に並列接続します。ADC基板の電源は別経路ですが、GNDは共通にします。
- 現行の超音波実装は **I²CではなくTrig/Echo** です。旧I²C版と配線を混同しないでください。
- この表はコネクタの物理的な端子順や電源電圧を保証するものではありません。接続前に実物の基板・モジュールと照合してください。
- HX711用D11/D12は、既存コードではSense拡張基板のJ1/J2をカットしてオンボードマイクを無効化する前提です。実機の基板仕様を確認してください。
- microSDのピン定義はCS=GPIO21、SCK=GPIO7、MISO=GPIO8、MOSI=GPIO9です。

## Arduino環境

`XIAO_ESP32S3_Control_Module.ino`を、同名フォルダ内の各ヘッダと一緒にArduino IDEで開きます。

- ボード：`XIAO_ESP32S3`（ESP32 Arduinoコア）
- シリアルモニタ：115200 bps
- 外部ライブラリ：`Adafruit ADS1X15`（依存ライブラリを含む）、`ESP32Servo`、`TinyGPSPlus`、`EspSoftwareSerial`
- IMU、HX711、SBUS、超音波の処理はリポジトリ内のヘッダに実装しています。

ライブラリのバージョンは固定していません。機能無効時にも読み込まれるヘッダがあるため、上記ライブラリを一通り用意してください。

サーボが動作する構成です。初回起動・書き込み後の確認は、プロペラやリンク機構が不用意に動かない安全な状態で行ってください。SBUSのフェイルセーフ情報は表示されますが、それだけでサーボが安全停止する実装ではありません。

## ADCと推力の値

設定は`ads1015_module.h`にあります。

| 項目 | コード上の設定 |
| --- | --- |
| I²Cアドレス | `0x48` |
| 入力 | A0−A1差動 |
| PGA | ×16（フルスケール±0.256 V） |
| データレート | 128 SPS |
| ポーリング間隔 | 8 ms |
| 保存する値 | 電圧［V］ |

上記は設定値です。単発変換の完了待ちや他処理を含むため、プログラム全体で128件/秒取得・保存するという意味ではありません。

シリアルでは、超音波の`err=`の後、サーボの`mg92b_deg=`の前に表示されます。

```text
... err=0 ads_a0_a1_v=0.012345 mg92b_deg=3.30 us=1535 ...
```

`ads_a0_a1_v=0.012345`は差動電圧0.012345 Vです。**推力への換算とADCのゼロ点補正は未実装**です。校正係数とゼロ点が決まったら、保存した電圧から後処理で換算できます。

ADCが検出できなければ`N/A`を表示し、約500 ms間隔で再接続を試みます。起動時の`[ADS1015]`初期化メッセージも確認してください。

## サーボ制御

以下はすべてコードの **0始まりの配列添字** で表記しています。送信機の表示名とは必ずしも一致しません。

### サーボ1（D2）

SBUSの`ch[1]`（シリアルの`CH(...)`の2番目）で制御します。

- 368 → 160度
- 1014 → 90度
- 1680 → 20度

### MG92Bサーボ2（D6）

旧STSの制御ロジックを角度オフセットからμsへ変換し、PWMで出力します。

- 中立1500 μs、出力範囲700〜2300 μs
- 150度の可動範囲を仮定し、約10.67 μs/度で変換
- `ch[8]`がHigh側：固定角モード。`ch[5]`の3位置で0 / 3.3 / 5.7度を選択
- それ以外：超音波距離を20〜30 cmに制限し、`距離 / 10 × 5`度に変換（20 cmで10度、30 cmで15度）
- 超音波値が無効（NaN等）の場合は角度オフセット0度

角度は指令値であり、実測角度やサーボからの位置フィードバックではありません。実機のリンクと安全な可動範囲に合わせ、`MG92B_*`定数を調整してください。試験用の強制往復動作`MG92B_DEBUG_FORCE_SWEEP`は現在0（無効）です。

## シリアルとSDログ

### シリアル表示

約500 msごとに、ループ周波数、SBUS、超音波、ADC、サーボ指令、IMU、GPSなどを1行に出力します。

- ADC：`ads_a0_a1_v=`（V）
- 超音波：`cm=`、`raw=`、`age_ms=`、`err=`
- サーボ2：`mg92b_deg=`、`us=`
- HX711を有効にした場合：`hx_g=`、`hx_raw=`

超音波のトリガ間隔設定は45 msです。中央値フィルタと、読み取り失敗時の直前値保持（500 msを基準に無効化）を使用します。`cm=`は保持・フィルタ後の値なので、`raw=`や`age_ms=`も併せて確認してください。

### 記録開始・停止

- SBUSの`ch[4]`：Highで開始、Lowで停止、Middleではシリアル手動トリガに従います。
- シリアルモニタから空行（改行のみ）を送ると、手動トリガがON/OFFします。SBUSがHigh/Lowの場合はそちらが優先されます。
- 記録中は約100 ms間隔（10 Hz設定）で`/log_<開始時のmillis>.csv`に書き込みます。
- microSDを取り外す前にログを停止し、ファイルを閉じてください。

CSVには時刻`ms`、SBUSの`ch[0]`〜`ch[5]`、超音波、`ads_a0_a1_v`、IMU、GPSを保存します。GPS由来の日時はUTCです。現在のCSV形式にはHX711の重量列やサーボ指令列はありません。

## 機能の切り替え

スケッチ先頭付近の`USE_*`定義を変更します。現在の設定は以下です。

```cpp
#define USE_HX711           0
#define USE_ADS1015         1
#define USE_IMU_LSM6DSV16X   1
```

HX711へ戻す場合は`USE_HX711=1`、`USE_ADS1015=0`にします。HX711は起動時とログ開始時に3秒間のテア処理を行うため、その間は無負荷で静止させてください。HX711の校正定数はスケッチ内の`g_hx_cfg`にあります。
